# Σύστημα Στατιστικών και Διάθεσης Πανεπιστημιακών Συγγραμμάτων (Prolog)

Αυτό το πρόγραμμα σε Prolog αποτελεί ένα διαδραστικό σύστημα διαχείρισης και ανάλυσης δεδομένων σχετικά με τη διάθεση πανεπιστημιακών βιβλίων (συγγραμμάτων) σε πανεπιστήμια, τμήματα και μαθήματα ανά ακαδημαϊκά έτη.

## 📋 Λειτουργίες Συστήματος

Το πρόγραμμα παρέχει ένα μενού επιλογών στον χρήστη μέσω της κονσόλας για την εκτέλεση των παρακάτω αναλύσεων:
* **Στατιστικά 1 έτους:** Εμφάνιση πανεπιστημίων, τμημάτων και μαθημάτων όπου διατέθηκε ένα βιβλίο σε ένα συγκεκριμένο έτος.
* **Στατιστικά πολλαπλών ετών:** Συγκεντρωτική προβολή της πορείας διάθεσης ενός βιβλίου σε ένα εύρος ετών.
* **Σύγκριση μεταξύ 2 ετών:** Αναλυτική καταγραφή των μαθημάτων/τμημάτων που προστέθηκαν ή αφαιρέθηκαν για ένα βιβλίο μεταξύ δύο ετών.
* **Σύγκριση 2 βιβλίων:** Άμεση σύγκριση στατιστικών (ποσοτικών και ποιοτικών) μεταξύ δύο διαφορετικών συγγραμμάτων για το ίδιο έτος σε επίπεδο Πανεπιστημίων, Τμημάτων ή Μαθημάτων.

## 🚀 Οδηγίες Εκτέλεσης

1. Βεβαιωθείτε ότι έχετε εγκατεστημένο το **SWI-Prolog**.
2. Τοποθετήστε στο ίδιο αρχείο τα απαραίτητα αρχεία δεδομένων (`universities.pl`, `departments.pl`, `courses.pl`, `books.pl`, `books_per_course.pl`).
3. Φορτώστε το αρχείο κώδικα στο περιβάλλον της Prolog.
4. Εκκινήστε την εφαρμογή καλώντας το κατηγόρημα:
   ```prolog
   ?- run.
   ```

* **Φιλτράρισμα Διπλοτύπων:** Διαθέτει ειδικούς μηχανισμούς (`filter_courses_by_department/4`) για την αποφυγή διπλότυπων καταγραφών όταν το ίδιο μάθημα προσφέρεται με διαφορετικά ID.
